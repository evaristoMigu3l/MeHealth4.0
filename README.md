# Me&Health 4.0 (MeHealth4.0)

A comprehensive, private, offline-first personal health tracking application built with React Native and Expo.

## Features

- **Symptom & Vitals Tracking:** Log and monitor symptoms, blood pressure, glucose, body measurements, sleep, mood, and water intake.
- **Medication & Reminders:** Keep track of prescribed medications, dosages, schedules, and local notifications.
- **AI Health Assistant:** Built-in AI assistant supporting text and vision models via secure local key storage (`expo-secure-store`).
- **Data Privacy:** Local-first architecture ensuring your health data stays on your device.
- **Data Export:** Export your health history to PDF, CSV, or full JSON backups.

## Tech Stack

- **Framework:** Expo (React Native managed workflow)
- **Navigation:** Expo Router (file-based routing)
- **State Management:** Zustand
- **Styling:** NativeWind (Tailwind CSS) & React Native StyleSheet
- **Security:** `expo-secure-store` for credentials & key isolation

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn
- Expo Go app on iOS/Android or an emulator

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/evaristoMigu3l/MeHealth4.0.git
   cd MeHealth4.0
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npx expo start
   ```
